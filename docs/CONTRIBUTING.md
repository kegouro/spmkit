# Contributing

SPM-Kit welcomes focused contributions to readers, numerical analysis, Fathom,
documentation, and validation evidence. The complete development contract is in
the repository [CONTRIBUTING.md](https://github.com/kegouro/spmkit/blob/main/CONTRIBUTING.md).

## External laboratory data

Before proposing a fixture:

1. confirm that you may share it;
2. state its license and redistribution status;
3. remove personal, confidential, and sample-identifying metadata where needed;
4. provide a SHA-256 checksum and expected format/channel behavior;
5. distinguish raw input from any processed reference;
6. record instrument family, acquisition mode, units, orientation, and relevant calibration;
7. state whether the sample identity can remain private.

If redistribution is not permitted, open a metadata-only issue. Do not upload
the file. A maintainer can discuss a private, lawful validation route without
turning restricted data into a public fixture.
