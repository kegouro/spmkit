# References

## Software

- **Gwyddion** — free standard for SPM data analysis; validation reference for SPM-Kit.
- **pycroscopy** — Python ecosystem for microscopy and spectroscopy data.

## Books

- **E. Meyer, H. J. Hug, R. Bennewitz** — *Scanning Probe Microscopy: The Lab on a Tip*.
- **R. García** — *Amplitude Modulation Atomic Force Microscopy* (dynamic / tapping modes).
- **K. L. Johnson** — *Contact Mechanics* (Hertz, Sneddon, adhesion: JKR/DMT).

## Classic papers

- **Binnig, Quate & Gerber (1986)** — invention of the AFM, *Phys. Rev. Lett.*
- **Hertz (1881)** — contact of elastic solids.
- **Sneddon (1965)** — indentation of a flat by a cone.

## Repository

- **SPM-Kit** — code, validation, and this document. [github.com/kegouro/spmkit](https://github.com/kegouro/spmkit)
