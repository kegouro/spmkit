# Glossary

| Term | Definition |
|---|---|
| **Cantilever** | Micro-lever that holds the tip; spring of constant $k$. |
| **Setpoint** | Reference value the feedback loop keeps constant. |
| **Snap-in** | Sudden jump to contact when the attractive gradient exceeds stiffness. |
| **Pull-off** | Adhesion force that retains the tip during retract; minimum of the curve. |
| **$E^*$ (reduced modulus)** | Effective contact stiffness: $E^* = E / (1 - \nu^2)$ with rigid tip. |
| **CPD / $V_{\text{CPD}}$** | Contact potential difference; work function difference divided by $e$. |
| **PSD** | Power spectral density: roughness distributed by spatial frequency. |
| **Hurst ($H$)** | Self-affinity exponent; linked to fractal dimension $D = 3 - H$. |
| **Quality factor ($Q$)** | $f_0/\Delta f_{\text{FWHM}}$; how sharp and lightly damped the peak is. |
| **Thermal tuning** | Calibrate $k$ from thermal noise via equipartition $\langle x^2 \rangle = k_B T / k$. |
| **$m_{\text{eff}}$** | Effective mass of the vibration mode: $m = k / (2\pi f)^2$. |
| **Mass sensing** | Measure added mass by the shift in resonance frequency: $\Delta f \propto \Delta m$. |
