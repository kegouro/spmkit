# Pharos Project

SPM-Kit is the AFM/SPM instrumentation child of **Pharos Project**, a broader
collection of open scientific and educational tools developed around
reproducibility, accessibility and transparent computation.

## What is Pharos?

Pharos is not a single application. It is the parent portfolio and visual seal;
SPM-Kit is one instrument inside it, specialized in scanning probe microscopy.
Inside SPM-Kit, five component identities divide computation, interaction,
discovery, synthetic truth and external validation. That hierarchy does not
change software authorship, repository ownership or scientific evidence level.

## Visual relationship

The portal uses the canonical segmented-lighthouse mark, warm night/paper
palette, Fraunces display type and Pharos footer signature. Component artwork is
kept inside its own named section. In particular, Fathom's teal mark identifies
the interactive workspace only; it is not the SPM-Kit or Pharos global logo.
