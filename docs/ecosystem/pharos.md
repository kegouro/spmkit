# Pharos Project

SPM-Kit is part of **Pharos**, a broader collection of open scientific tools
developed around reproducibility, accessibility, and transparent computation.

## What is Pharos?

Pharos is not a single application — it is a portfolio philosophy: scientific
software that is open-source, traceable, and honest about its limitations. SPM-Kit
is one of its components, specialized in scanning probe microscopy.
